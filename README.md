# For Mishy ✦

An interactive web surprise keepsake featuring a gift box reveal, floating bouquet of eternal flowers, and an indie RPG pixel-style dialogue with Nailong.

## ✨ Features
- **Cinematic Unboxing Reveal**: An interactive gift box that pops its lid, explodes with golden starlight shine, and releases the flowers into a gilded velvet keepsake frame.
- **Pixel Indie Game Dialogue**: A retro dialogue box at the bottom featuring authentic typewriter animation, punctuation pacing, and sound blips.
- **Cinematic Finale**: A spotlight focus on the flowers with dimming ambient vignette and heart icon.
- **Background Music & Sound Engine**: Plays *"Just the Way You Are"* by Bruno Mars with built-in fallback Web Audio API romantic music box synthesizer and celebratory fanfares.
- **Ambient Canvas**: Floating sakura petals and golden fairy stardust.

## 🚀 Running Locally
You can open `index.html` directly in any modern browser, or run a local server:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000`.
